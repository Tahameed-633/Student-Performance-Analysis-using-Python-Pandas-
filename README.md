# 📊 Student Performance Analysis using Python & Pandas

This project analyzes a student performance dataset using **Python**, **Pandas**, and **Matplotlib**. It demonstrates data preprocessing, statistical analysis, correlation analysis, grade classification, and data visualization techniques.

---

## 🚀 Technologies Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

---

## 📁 Dataset

**File:** `student_dataset.csv`

The dataset contains the following information:
- Student Name
- Department
- Credits Completed
- CGPA

---

## 📈 Features & Analysis

- Display dataset information
- Generate statistical summary
- Department-wise CGPA analysis
  - Maximum CGPA
  - Minimum CGPA
  - Average CGPA
  - Standard Deviation
- Department-wise Credits analysis
  - Maximum Credits
  - Minimum Credits
  - Average Credits
- Count total students
- Department-wise student count
- Identify high-performing students
- Filter students using different conditions
- Automatic grade classification (A+ to F)
- Correlation analysis between Credits and CGPA

---

## 📊 Data Visualizations

- 📌 Department-wise Student Count (Bar Chart)
- 📌 CGPA Distribution (Histogram)
- 📌 CGPA Box Plot
- 📌 Credits vs CGPA (Scatter Plot)
- 📌 Department-wise Mean CGPA with Standard Deviation (Error Bar Chart)
