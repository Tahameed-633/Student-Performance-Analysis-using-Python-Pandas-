# 📊 Student Performance Analysis using Python & Pandas

A Python-based data analysis project that demonstrates data manipulation, statistical analysis, CSV file handling, and data visualization using **Pandas**, **NumPy**, and **Matplotlib**. The project analyzes student academic performance through filtering, grouping, sorting, grade calculation, and graphical representation.

---

## 📌 Project Overview

This project was developed as part of the **Statistics for Data Science** course. It showcases the fundamentals of data analysis using Python by working with a student dataset.

The project includes:
- Data manipulation with Pandas
- Statistical analysis
- CSV file handling
- Department-wise analysis
- Student grade calculation
- Data visualization

---

## 🚀 Features

- Create and manipulate Pandas DataFrames
- Read and write CSV files
- Add, update, and delete rows & columns
- Boolean filtering
- Sorting and indexing
- GroupBy operations
- Department-wise analysis
- Statistical summary
- Grade calculation using functions

- Data visualization

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/student-performance-analysis-python.git
```

2. Navigate to the project folder

```bash
cd student-performance-analysis-python
```

3. Install the required libraries

```bash
pip install pandas numpy matplotlib
```

4. Run the project

```bash
python "Student Data Analysis.py"
```
